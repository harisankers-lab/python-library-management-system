# Library Management System | Python

A library management system developed using Python to manage book inventory, library members and borrowing transactions through object-oriented programming.

### Features
- Display book catalogue and available copies.
- Manage student and teacher membership.
- Issue books with member-specific borrowing limits.
- Return previously borrowed books.
- Handle unavailable books and invalid requests.
- Display final inventory and borrowing status.

### Technologies
- Python 3
- Jupyter Notebook

### Concepts Practised
Object-oriented programming, classes, objects, encapsulation, inheritance, method overriding, polymorphism, lists and dictionaries.

### Project Structure
- `library_casestudy.ipynb` – Notebook containing class implementations, tasks, execution and outputs.

### Run
Open the notebook using Jupyter Notebook, JupyterLab or Google Colab and execute the cells sequentially.
